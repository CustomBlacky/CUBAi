# CUBAi — бесплатная версия

Эта версия использует Hugging Face Inference Providers вместо OpenAI API.

Переменная Render:
- `HF_TOKEN` — токен Hugging Face
- `HF_CHAT_MODEL` — `Qwen/Qwen2.5-7B-Instruct`

Токен нельзя публиковать в GitHub.

AI Render отключён в этой версии, чтобы не требовать платный image API.
